# External architecture influences

These sources inform the proposed ADRs. They do not substitute for project-specific scientific validation.

1. Wilkinson MD, et al. *The FAIR Guiding Principles for scientific data management and stewardship*. Scientific Data 3, 160018 (2016). DOI: 10.1038/sdata.2016.18.
2. W3C. *PROV-O: The PROV Ontology*. W3C Recommendation, 30 Apr 2013. https://www.w3.org/TR/prov-o/
3. Research Object Crate community. *RO-Crate Metadata Specification 1.3*. Recommendation, 22 Jun 2026. https://w3id.org/ro/crate/1.3
4. NIH. *Enhancing Reproducibility through Rigor and Transparency* and related current rigor/reproducibility guidance.

Architectural interpretation used here:
- FAIR supports findability, accessibility, interoperability, reusability and detailed provenance for research objects.
- W3C PROV supplies a general provenance vocabulary around entities, activities, and agents.
- RO-Crate 1.3 provides a current machine-readable research-object packaging model using JSON-LD.
- NIH guidance emphasizes rigorous, transparent design, analysis, interpretation, reporting, and reproducibility.
