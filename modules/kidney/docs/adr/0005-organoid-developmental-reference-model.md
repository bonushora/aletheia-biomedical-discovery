# ADR-KR-0005 — Kidney Organoid Developmental Reference Model

- **Status:** Proposed
- **Date:** 2026-10-06
- **Parents:** ADR-0010, ADR-KR-0004

## Decision
KRRCP will distinguish organoid state from mature kidney tissue and will represent developmental reference mappings as contextual evidence, not identity by default.

Reference mappings must retain source atlas/study, developmental stage, tissue context, mapping method, uncertainty, and known mismatches. A reference model may be versioned and superseded as stronger evidence appears.
