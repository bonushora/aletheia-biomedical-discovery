# Integration boundary

The ADR foundation is integrated into the local, independent `aletheia-biomedical-discovery` repository.

## Locally qualified

- ADR structure, numbering, status, and internal references.
- Human-authority and evidence-governance invariants.
- Federated topology and compatibility safeguards accepted in ADR-0016.
- Documentation scaffolding for contracts, schemas, evidence packages, and Research Control Planes.
- Local Git baseline and reproducible evidence manifest.

## Outside this integration

- Remote repository creation, push, release, or publication.
- Executable contract or schema versions.
- Migration or mutation of `kidney-regeneration-research`.
- Scientific, biomedical, or clinical validation.
- Compatibility claims for untested future Control Planes.
