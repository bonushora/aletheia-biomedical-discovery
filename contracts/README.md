# Contracts

Contracts define the explicitly versioned integration boundary between Aletheia Core and federated Research Control Planes. They describe interoperable inputs, outputs, identities, and evidence expectations without importing an implementation repository.

Contract authority is architectural and technical. It does not decide scientific truth, change scientific state, or replace a human scientific decision. Scientific policy remains governed by the applicable ADRs and human authority boundary.

The first executable family is [`aletheia.research-control-plane-descriptor` v0.1.0](research-control-plane-descriptor/0.1.0/CONTRACT.md), with registry status `EXPERIMENTAL`. It has one qualified local consumer, `kidney-regeneration-research`, bound to exact subject and qualification commits. This compatibility fact was not remotely published and is not scientific or clinical validation. See [versioning](VERSIONING.md), [the registry](REGISTRY.json), and [the compatibility matrix](COMPATIBILITY-MATRIX.json).
