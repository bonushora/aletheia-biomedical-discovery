# Research Control Planes

A Research Control Plane implements a domain-specific workflow behind explicitly versioned Aletheia contracts and schemas while retaining independent repository governance, history, CI, release, and scientific review.

Kidney Regeneration Research is the first federated Control Plane. This repository contains only its ADR foundation under `modules/kidney/docs/adr/`; it does not import, move, or mutate Kidney source code or biomedical data.

The first interface version is `NOT_ESTABLISHED`.
